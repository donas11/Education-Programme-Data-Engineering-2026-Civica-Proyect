# Education-Programme-Data-Engineering-2026-C-vica-Proyect
Este proyecto consiste en la construcción de un pipeline de datos moderno, confiable y escalable,  datos desde Fuente de datos de API/Scraping -> archivos CSV  hacia un almacén de datos en la nube. Utilizando  dlt para la ingesta y modelado de datos crudos, Snowflake como motor de almacenamiento y  computo,  dbt para la transformación
